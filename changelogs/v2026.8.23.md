# v2026.8.23

## PvP: Enemy Frames

- New **Enemy Frames** overlay showing the enemy team's HP, disciplines, and current targets. Enemy players are picked up as they appear in the logs and replaced oldest-first when the roster fills
- Added **Incoming Damage** overlay showing who is hitting you over the past 20 seconds, with an optional full-fight total per attacker
- PvP overlays now have their own section in the overlay list and settings
- Enemy frames clear automatically when leaving a PvP area and the roster resets between matches
- Warzones now end when the Rebirth effect is applied and start on initial deserter detection. Arena/Warzone boundary detection further refined

## Raid Frames

- Added a **Clear All** button in `Rearrange` mode
- Added an **Effect Horizontal Offset** setting to nudge effect icons left or right
- Effect icons are now slightly smaller relative to bar height
- Renamed "Prioritize Stacked Effects" to "Emphasize Effect Charges"
- Raid frame auto-assignment is more reliable when a character is missing from the screenshot, and the Windows taskbar no longer appears in screenshots because the overlay no longer steals focus from the game

## Effect Modifiers

- New modifier triggers: **Healing Dealt**, **Killing Blow** (with victim filter), and **Resource Spent** (optionally scaling the duration change by the amount spent)
- Modifiers can now **cancel** an effect instead of adjusting its duration
- Modifier internal cooldowns can now start from the effect's initial application and be scaled by alacrity

## Other

- Operations timer now auto-starts in Dxun, Gods from the Machine, and R-4 Anomaly
- Numpad keys can now be bound as hotkeys
- Combat log tooltips in the data explorer now show HP
- Final HP summary in the overview no longer counts effect lost / target cleared events
- Improved death recap formatting
